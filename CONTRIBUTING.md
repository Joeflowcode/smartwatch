# Contributing

1. Create a branch from `main`.
2. Keep the app runnable; prefer small commits.
3. Run `npm run lint && npm run typecheck && npm test` before PRs.
4. Do not commit secrets or production data dumps.
5. Avoid casino-style UX and guaranteed-outcome language.
6. Update `PROJECT_STATUS.md` when completing milestones.

Security-sensitive changes require extra review of RLS and entitlement paths.
